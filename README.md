# Emma Sophie Hare — Developer Portfolio

A simple personal portfolio website built with HTML, CSS and JavaScript.

## Files

- `index.html` — all portfolio content
- `style.css` — all visual styling
- `script.js` — small JavaScript additions
- `assets/images/` — portrait and future images
- `assets/cv/` — place your CV PDF here

## Before publishing

Replace these placeholders in `index.html`:

1. `YOUR-EMAIL@example.com`
2. `YOUR-USERNAME`
3. `YOUR-DESIGNDESK-REPOSITORY`

Add your CV as:

`assets/cv/emma-sophie-hare-cv.pdf`

Replace the placeholder portrait by either:

- replacing the file path in the HTML with your image filename, or
- putting your image in `assets/images/` and updating the `<img src="">`.

## GitHub Pages

1. Create a new public GitHub repository.
2. Upload these files to the repository root.
3. Open the repository's **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`.
7. Save.
8. GitHub will provide your live portfolio URL.
